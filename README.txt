DANIELLE NICHOLE ACOSTA — ONE-PAGE PORTFOLIO

To preview:
1. Unzip the folder.
2. Double-click index.html to open the website in your browser.

To edit:
- index.html contains all page content and links.
- styles.css contains the styling.
- assets/ contains the actual project screenshots from the portfolio document.

To publish for free:
- Drag this folder's contents (index.html, styles.css, script.js, assets/) to Netlify Drop at https://app.netlify.com/drop or deploy via an S3 + CloudFront site.
- The live-project buttons are already linked.
- The local projects link to the GitHub profile until you choose specific repository URLs.

No React setup, npm install, or backend is required for this portfolio website.
The Google Fonts stylesheet uses an internet connection; fallback fonts work offline.
